Recording some knowledge from my optimization studies. I find that these details tend to be forgotten after a while, and content varies across different sources and books, so I'm consolidating them here.

## 1. Step Size Selection

### (1) Trivial Step Sizes

- **Constant step size:** Chosen empirically and dependent on initialization. Too large causes oscillation/divergence; too small leads to slow convergence. Only with a suitable value do we get fast, stable progress. In short, not very intelligent.
- **Diminishing step size:** Very broadly applicable. When the function is non-smooth or gradients are noisy, the [Robbins–Monro rule](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=Robbins%EF%BC%8DMonro+rule&zhida_source=entity) guarantees convergence, but the [convergence rate](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E6%94%B6%E6%95%9B%E9%80%9F%E7%8E%87&zhida_source=entity) is slow. Typically used when conditions are poor and [convergence speed](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E6%94%B6%E6%95%9B%E9%80%9F%E5%BA%A6&zhida_source=entity) is not a priority.

### (2) Line Search

**1. Exact line search**[1](#ref_1)

Typically non-trivial. Under a unimodal interval assumption, using a zeroth-order oracle we have golden-section search and [quadratic interpolation](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E4%BA%8C%E6%AC%A1%E6%8F%92%E5%80%BC%E6%B3%95&zhida_source=entity). The former converges linearly with ratio ~0.618; the latter converges superlinearly with order 1.3. With a first-order oracle, quadratic and cubic interpolation are also available, with convergence orders 1.618 and [second-order convergence](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E4%BA%8C%E9%98%B6%E6%94%B6%E6%95%9B&zhida_source=entity), respectively. With a second-order oracle, Newton's method achieves at least quadratic convergence. The closedness of the [algorithm mapping](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E7%AE%97%E6%B3%95%E6%98%A0%E5%B0%84&zhida_source=entity) and [global convergence](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E5%85%A8%E5%B1%80%E6%94%B6%E6%95%9B%E6%80%A7&zhida_source=entity) can be found on page 185 of [1](#ref_1).

**2. Inexact line search**

Easy to implement and highly practical.

The [Armijo condition](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=Armijo%E5%87%86%E5%88%99&zhida_source=entity) guarantees sufficient decrease: $f(x^k)-f(x^k+\alpha d) \geq -c\cdot\alpha d^T \nabla f(x^k)$, where $\alpha$ is the step size, $d$ is the search direction, and $c$ is a tunable parameter, usually $c\in(0,1)$. This can be implemented via backtracking line search.

The [weak Wolfe conditions](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E5%BC%B1Wolfe%E5%87%86%E5%88%99&zhida_source=entity) additionally impose a requirement on the [slope](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E6%96%9C%E7%8E%87&zhida_source=entity); the [strong Wolfe conditions](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E5%BC%BAWolfe%E5%87%86%E5%88%99&zhida_source=entity) impose a stricter slope requirement, avoiding overshoot and oscillation. In general, the weak version is sufficient; if you are confident in your implementation, the strong version can be used, though in practice their performance is similar. The weak version actually has distinctive advantages: it is more robust on [ill-conditioned functions](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E7%97%85%E6%80%81%E5%87%BD%E6%95%B0&zhida_source=entity) and is more commonly used. The strong version is often paired with line search methods based on interpolation or fitting, which typically assume the objective is twice [continuously differentiable](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E8%BF%9E%E7%BB%AD%E5%8F%AF%E5%BE%AE&zhida_source=entity) to avoid ill-conditioning.

The weak Wolfe conditions can be implemented via the Lewis & Overton line search:

$$
l \leftarrow 0\ (\text{lower bound}),\ u \leftarrow +\infty\ (\text{upper bound}),\ \alpha \leftarrow 1 \\
\text{repeat} \\
\quad \text{if} \ \ f(x^{k})-f(x^{k}+\alpha d)<-c_{1}\alpha d^{T}\nabla f(x^{k}) \ \ (\alpha \text{ too large}) \\
\quad \quad u \leftarrow \alpha \\
\quad \text{else if} \ \ d^{T}\nabla f(x+\alpha d )<c_{2}d^{T}\nabla f(x^{k}) \ \ (\alpha \text{ too small}) \\
\quad \quad l \leftarrow \alpha \\
\quad \text{else} \\
\quad \quad \text{return} \ \ \alpha \ \ (\text{exit if either if or else if holds}) \\
\quad \text{if} \ \ u<+\infty \\
\quad \quad \alpha \leftarrow (l+u)/2 \ \ (\text{bisect between previous } \alpha \text{ and current } \alpha) \\
\quad \text{else} \\
\quad \quad \alpha \leftarrow 2l \ \ (\text{twice the previous } \alpha) \\
\text{end repeat}
$$

In some examples, backtracking line search and exact line search require nearly the same number of iterations for a given accuracy, but the per-step [time complexity](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E6%97%B6%E9%97%B4%E5%A4%8D%E6%9D%82%E5%BA%A6&zhida_source=entity) is vastly different.

## 2. First-Order Methods

### (1) Gradient Descent

For the gradient flow $\dot x(t)=\nabla f(x(t))$, $x(0)=x_{0}$, if $f$ satisfies a first-order Lipschitz condition, then by the Picard existence and uniqueness theorem the equation has a unique solution. Moreover, if $f$ is positive definite near $x_0$ and its gradient is (semi-)negative definite, then $f$ itself can serve as a (local) Lyapunov function, implying that the gradient flow converges to a stationary point of $f$.

Discretizing via forward Euler yields the standard gradient step $x^{k+1}=x^{k}-\alpha \nabla f(x^{k})$, where $\alpha$ is the discrete step size. Although forward Euler can overshoot easily, its computational cost is much smaller than implicit discretization methods (such as third-order Hermite–Simpson, implicit midpoint, backward Euler) or fourth-order Runge–Kutta. Naturally, one might consider a more stable [discretization scheme](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E7%A6%BB%E6%95%A3%E5%8C%96%E6%96%B9%E6%B3%95&zhida_source=entity) to reduce oscillation in gradient steps under large [condition numbers](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E6%9D%A1%E4%BB%B6%E6%95%B0&zhida_source=entity). But a more fundamental fix is to introduce "generalized momentum," i.e., to study accelerated first-order methods.

For ordinary gradient descent on convex functions with a first-order Lipschitz condition, one can prove $|\nabla f(x^{k})| \leq \frac{\beta}{\sqrt{k(k+1)}}||x^{*}-x^{0}||$, and further $f(x^{k})- f(x^{*})\leq \frac{\beta}{2(k+1)}||x^{*}-x^{0}||^{2}$, i.e., arithmetic (sublinear) convergence.

When the condition is strengthened to strong convexity, the result is strengthened to linear convergence, which can be seen by studying the quadratic case. For a quadratic, gradient descent becomes $x^{k+1}=x^{k}-g^{k}/r^{k}$, where $r$ is the Rayleigh quotient. Using the explicit ellipsoid formula and the Kantorovich [inequality](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E4%B8%8D%E7%AD%89%E5%BC%8F&zhida_source=entity), for $E(x)=\frac{1}{2}(x-x^{*})^{T}Q(x-x^{*})$ we easily obtain $E(x^{k+1})\leq (\frac {A-a}{A+a})^{2}E(x^{k})=(\frac {r-1}{r+1})^{2}E(x^{k})$, where the convergence ratio depends only on the ratio of the largest to smallest eigenvalues of $Q$ (the condition number). In the non-quadratic case, the convergence ratio is no worse than this value (matching the quadratic case near a local optimum). This naturally motivates scaling to improve the condition number and accelerate convergence: for $Ty=x$, let

$$
h(y)=f(Ty)\Rightarrow d_{y}=-\nabla h=-T^{T}\nabla f\Rightarrow d_{x}=-TT^{T}\nabla f, \ \ \nabla ^{2}h(y)=T^{T}\nabla ^{2}f(Ty)T
$$

which changes both the search direction and the condition number. Clearly, for an [orthogonal matrix](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E6%AD%A3%E4%BA%A4%E7%9F%A9%E9%98%B5&zhida_source=entity) $T$, the search direction is unchanged and the convergence speed is also unchanged.

For non-quadratic strongly [convex functions](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E5%87%B8%E5%87%BD%E6%95%B0&zhida_source=entity) (Hessian positive definite and bounded), exact line search gives $f(x^{k+1})-f^{*}\leq (1-\frac{1}{r})(f(x^{k})-f^{*})$, and backtracking line search with the Armijo condition gives $f(x^{k+1})-f^{*}\leq (1-\frac{2c}{r})(f(x^{k})-f^{*})$, both linear convergence.

### (2) Accelerated First-Order Methods

## 3. Modified Damped Newton's Method

Discretizing $\dot x(t)=-\nabla^{-2}f(x(t))\nabla f(x(t))$ yields $x^{k+1}=x^{k}+d^{k}=x^{k}-\alpha H^{-1}(x^{k})\nabla f(x^{k})$. As a second-order algorithm, it handles poor conditioning and slow convergence well: the iteration count drops dramatically and convergence is fast, but the per-step cost rises substantially. Solving for the Newton step essentially means solving the [linear system](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E7%BA%BF%E6%80%A7%E6%96%B9%E7%A8%8B%E7%BB%84&zhida_source=entity) $Md=-\nabla f(x)$, which raises some technical issues:

### (1) Damping and Tikhonov Regularization

Damping means that the Newton step size $\alpha$ is approximately 1 near a local optimum and shrinks when far away. Regularization ensures positive definiteness for inversion, avoiding ill-conditioning during iteration, guaranteeing descent, and handling numerical [round-off errors](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E8%88%8D%E5%85%A5%E8%AF%AF%E5%B7%AE&zhida_source=entity) and singularities.

When $f$ is convex, the Hessian must be positive definite; choosing $M=\nabla^{2}f(x)+\varepsilon I$, $\varepsilon = \min\{1, ||\nabla f(x)||_{\infty}\}/10$ corresponds to adding a penalty term $\varepsilon \Delta x^{T}\Delta x$, $\Delta x=x^{k+1}-x^{k}$ to the objective. Positive definiteness can be checked via Cholesky decomposition.

The non-convex case is slightly more involved and requires consideration of the properties of the Bunch–Kaufman decomposition.

### (2) Matrix Factorizations

When $f$ is convex, requiring positive definiteness, the Cholesky decomposition $M=LL^{T}$ can be used to solve the Newton step. If non-convex, the Hessian may be indefinite, and the Bunch–Kaufman decomposition $M=LDL^{T}$ can be used, where $D$ is a block-diagonal matrix ([tridiagonal matrix](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E4%B8%89%E5%AF%B9%E8%A7%92%E7%9F%A9%E9%98%B5&zhida_source=entity)) with blocks of size one or two: first-order blocks correspond to non-negative eigenvalues, and second-order blocks have one positive and one negative eigenvalue, making it easy to regularize and correct to obtain $\tilde D$.

### (III) Convergence

It can be shown that Newton's method achieves second-order convergence near a local optimum. Furthermore, a scaling transformation can be introduced:

$$
Ty=x，T=(\nabla ^{2}f(x^{k}))^{-\frac{1}{2}}
$$

The gradient step with respect to $y$ corresponds to the Newton step with respect to $x$, and the convergence rate of the $y$-gradient step is determined by the condition number of $(\nabla ^{2}f(x^{k}))^{-\frac{1}{2}}\nabla^{2}f(x)(\nabla ^{2}f(x^{k}))^{-\frac{1}{2}}$.

## IV. [Conjugate Direction Methods](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E5%85%B1%E8%BD%AD%E6%96%B9%E5%90%91%E6%B3%95&zhida_source=entity)

### (I) Linear [Conjugate Gradient Method](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E5%85%B1%E8%BD%AD%E6%A2%AF%E5%BA%A6%E6%B3%95&zhida_source=entity) (linear CG)

This method actually originates from an efficient large-scale linear solver (usable as either a direct or [iterative method](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E8%BF%AD%E4%BB%A3%E6%B3%95&zhida_source=entity)) that solves $Ax=b$ for positive definite $A$. This is equivalent to solving the optimization problem $\underset{x}{min}\frac{1}{2}x^{T}Ax-b^{T}x$. For quadratic problems, this method represents a compromise between gradient descent and Newton's method: the former follows a piecewise linear path, the latter reaches the solution in one step, while the conjugate direction method finds conjugate directions for the problem and proceeds along them. For $n$ conjugate directions $\{ u^{i}\}$, the exact step size can be used:

$$
\alpha \leftarrow \frac{b^{T}u^{k}-(x^{k})^{T}Au^{k}}{(u^{k})^{T}Au^{k}},x^{k+1}\leftarrow x^{k}+\alpha u^{k}
$$

to obtain the exact solution of $Ax=b$ in $n$ steps.

By applying conjugate Gram-Schmidt [orthogonalization](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E6%AD%A3%E4%BA%A4%E5%8C%96&zhida_source=entity) to a set of [linearly independent vectors](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E7%BA%BF%E6%80%A7%E6%97%A0%E5%85%B3%E5%90%91%E9%87%8F%E7%BB%84&zhida_source=entity) $\{v^{i}\}$:

$$
u^{k}=v^{k}\sum_{j=1}^{k-1}{proj_{u^{j}}(v^{k})},\ \ proj_{u}(v)=\frac{<u,v>_{A}}{<u,u>_{A}}u,\ \ <u,v>_{A}=u^{T}Av
$$

conjugate directions can be obtained. However, this still requires a set of linearly independent vectors, and each $v$ must be projected onto all previous $u$, giving a computational complexity of $O(\frac {k(k-1)}{2})=O(k^2)$, i.e., $O(n^{2})$, which is quite high. Nevertheless, some remarkably elegant results can be proven:

By choosing $v^{k}=b-Ax^{k}$ [incrementally](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E5%A2%9E%E9%87%8F%E5%BC%8F&zhida_source=entity) (constructing a [recurrence relation](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E9%80%92%E6%8E%A8%E5%85%B3%E7%B3%BB&zhida_source=entity) for $v^{k}$), and noting that $proj_{u^{j}}(v^{k})=0,\forall j\leq k-2$, we obtain a short recursion:

$$
u^{k}=v^{k}\sum_{j=1}^{k-1}{proj_{u^{j}}(v^{k})}=v^{k}+ \frac {||v^{k}||^{2}}{||v^{k-1}||^{2}}u^{k-1}
$$

The final algorithm is as follows, requiring only the matrix-vector product $Au^{k}$. This brings an additional benefit: sparsity is implicitly accounted for, without needing [heuristic methods](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E5%90%AF%E5%8F%91%E5%BC%8F%E6%96%B9%E6%B3%95&zhida_source=entity) to preserve sparsity in factorized forms of $A$.

$$
x^{1}\leftarrow x_{init} ,v^{1} \leftarrow b-Ax^{1} ,u^{1}\leftarrow v^{1} , k \leftarrow 1 \\ while \ \ v^{k}\ne 0 \ \ (||v^{k}||\geq \varepsilon) \\ \ \ \ \ \ \  \alpha \leftarrow \frac{||v^{k}||^{2}}{(u^{k})^{T}Au^{k}} \\ \ \ \ \ \ \ x^{k+1}\leftarrow x^{k}+\alpha u^{k} \\ \ \ \ \ \ \ v^{k+1}\leftarrow v^{k}-\alpha Au^{k} \\  \ \ \ \ \ \ \beta \leftarrow \frac{||v^{k+1}||^{2}}{||v^{k}||^{2}} \\ \ \ \ \ \ \ u^{k+1}\leftarrow v^{k+1}+\beta u^{k} \\ \ \ \ \ \ \ k \leftarrow k+1 \\end  \ \ while \\return \ \ x^{k}
$$

Moreover, this method is arguably one of the greatest [linear solvers](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E7%BA%BF%E6%80%A7%E6%B1%82%E8%A7%A3%E5%99%A8&zhida_source=entity): it maintains a remarkably small number of iterations even under fairly large condition numbers.

## V. [BFGS Method](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=BFGS%E6%B3%95&zhida_source=entity)

For problems of dimension $\mathbb R^{n }$, the gradient step has [computational cost](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E8%AE%A1%E7%AE%97%E6%88%90%E6%9C%AC&zhida_source=entity) $O(N)$, while the Newton step has [storage cost](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E5%AD%98%E5%82%A8%E6%88%90%E6%9C%AC&zhida_source=entity) $O(N^{2})$ and computational cost $O(N^{3})$. Furthermore, when the quadratic approximation performs poorly, the [cost-effectiveness](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E6%95%88%E8%B4%B9%E6%AF%94&zhida_source=entity) of the Newton step is unfavorable. When the Hessian is not positive definite, infinite step sizes or ascent steps can occur. For the matrix $M$ in $Md=-\nabla f(x)$, we would like to avoid computing [second derivatives](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E4%BA%8C%E9%98%B6%E5%AF%BC&zhida_source=entity) to reduce computation, keep the matrix lightweight and compact to reduce storage, while still incorporating [curvature](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E6%9B%B2%E7%8E%87&zhida_source=entity) information and guaranteeing descent directions — ideally also admitting a [closed-form solution](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E9%97%AD%E5%BC%8F%E8%A7%A3&zhida_source=entity).

### (I) Derivation

$$
\nabla f(x+d)=\nabla f(x)+\nabla ^{2}f(x)d +\int_{0}^{1}(\nabla^{2}f(x+td)-\nabla^{2}f(x))dt \\ \Rightarrow \nabla f(x)-\nabla f(y)\approx H(x-y)
$$

Denoting the above approximation as $\Delta g= M\Delta x$, called the secant condition, we avoid computing the inverse by rewriting it as $\Delta x=B\Delta g,MB=I$, using gradient differences to approximate the Hessian. Clearly this linear system is underdetermined. Suppose the iteration reaches step $k$, with known $B^{k}$, and define $\Delta x=x^{k+1}-x^{k},\Delta g=\nabla f(x^{k+1})-\nabla f(x^{k})$.

Under the convexity assumption, based on the [prior](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E5%85%88%E9%AA%8C&zhida_source=entity) $B^{k}$, solve the optimization problem $\\\underset B{min}||B-B^{k}||^{2} \\　s.t.B=B^{T} \\ 　　 \Delta x=B \Delta g$

Since the entries of $B$ have different scales, a scaling is applied. Let the average Hessian before and after the update be $H= \int _{0}^{1}\nabla^{2}f((1-\tau)x^{k}+\tau x^{k+1})d\tau$:

$\\\underset B{min}||H^{1/2}(B-B^{k})H^{1/2}||^{2} \\　s.t.B=B^{T} \\ 　　 \Delta x=B \Delta g$

This yields a closed-form solution independent of $H$, giving the BFGS update:

$$
B^{k+1}=(I- \frac {\Delta x\Delta g^{T}}{\Delta g^{T}\Delta x})B^{k}(I- \frac {\Delta g\Delta x^{T}}{\Delta g^{T}\Delta x})+\frac {\Delta x\Delta x^{T}}{\Delta g^{T}\Delta x}
$$

with $B^{0}=I$.

### (II) Guaranteeing Descent and Convergence

To guarantee descent, i.e., $B^{k}\succ 0$, it suffices to show that $\Delta g ^{T}\Delta x >0$. Under strong convexity, this condition holds automatically, and only the Armijo rule is needed to obtain the step size. For nonconvex, nonsmooth cases, an inexact line search satisfying the weak Wolfe conditions suffices to guarantee descent.

The BFGS algorithm has per-step complexity $O(N^{2})$ and achieves [superlinear convergence](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=2&q=%E8%B6%85%E7%BA%BF%E6%80%A7%E6%94%B6%E6%95%9B&zhida_source=entity). For functions with bounded sublevel sets and Lipschitz continuous gradients, the cautious update condition guarantees convergence (before 2001, no algorithm could guarantee BFGS convergence on [nonconvex functions](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E9%9D%9E%E5%87%B8%E5%87%BD%E6%95%B0&zhida_source=entity); practice merely showed that BFGS almost never failed on nonconvex problems. After this condition was proposed in 2001, some questioned whether it was redundant. It was not until the 2013 paper "A perfect example for the BFGS method," which constructed a low-dimensional function where BFGS + Wolfe conditions fail to converge, that this 2001 result received due attention). However, due to the characteristics of the BFGS method, divergence typically occurs in the early optimization phase; near local minima the cautious update condition is satisfied, so in practice the method remains stable even without this safeguard.

$$
B^{k+1}= \begin{cases} (I- \frac {\Delta x\Delta g^{T}}{\Delta g^{T}\Delta x})B^{k}(I- \frac {\Delta g\Delta x^{T}}{\Delta g^{T}\Delta x})+\frac {\Delta x\Delta x^{T}}{\Delta g^{T}\Delta x}  &   &{\text{if }\Delta g^{T}\Delta x>\varepsilon||g_k||\Delta x^{T}\Delta x,\varepsilon =10^{-6}}  \\B^{k}&  &{\text{otherwise}}  \end {cases}
$$

### (III) Limited-Memory (L-BFGS)

Far from a local minimum, curvature information is less important — especially for nonconvex functions, where steps many iterations back may correspond to different curvature directions. However, BFGS retains all historical information, and after many iterations $B^{k}$ becomes dense, slowing down storage and computation. A forgetting mechanism can be introduced to prevent historical information from interfering and to bound the matrix rank. Defining $s^{k}=x^{k+1}-x^{k},y^{k}=g^{k+1}-g^{k},\rho^{k}=1/{s^{k}}^{T}y^{k}$, a sliding window of length $m$ is introduced: $B^{k+1}\leftarrow BFGS(B^{k},y^{k},s^{k}),k\leftarrow k+1$, looped $m$ times (equivalent to ordinary BFGS when the window is not full). The complexity is $O(mn^2)$, but since each step is an incremental update, the entire sliding window need not be recomputed. This leads to an [equivalent algorithm](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E7%AD%89%E4%BB%B7%E7%AE%97%E6%B3%95&zhida_source=entity) — the two-loop recursion — with complexity of only $O(mn)$.

$$
d \leftarrow g^{k} \\ for\ \ i=k-1,k-2,...,k-m \\ \ \ \ \ \ \ \ \alpha^{i}\leftarrow \rho^{i}{s^{i}}^{T}d \\ \ \ \ \ \ \ \ d \leftarrow d-\alpha^{i}y^{i} \\ end \ \ for \\ \gamma \leftarrow \rho^{k-1}{y^{k-1}}^{T}y^{k-1} \\ d \leftarrow d/\gamma \\ for \ \ i=k-m,k-m+1,...,k-1 \\ \ \ \ \ \ \ \ \beta \leftarrow \rho^{i}{y^{i}}^{T}d \\ \ \ \ \ \ \ \ d \leftarrow d+s^{i}(\alpha^{i}-\beta) \\ end\ \ for \\ return\ \ search \ \ direction  \ \ d
$$

### (IV) Nonsmooth BFGS

When the objective function is nonsmooth or piecewise smooth, gradients may not exist, negative subgradient directions may not be descent directions, and curvature can become large or singular. Algorithms typically fail when handling nonsmooth problems. In 2013, Lewis & Overton devised an approach (with modest convergence rates, but acceptable for [nonsmooth optimization](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E5%85%89%E6%BB%91%E4%BC%98%E5%8C%96&zhida_source=entity)). For nonsmooth cases, the strong Wolfe conditions can be problematic, while the weak version works properly.

Since in the nonsmooth case the gradient norm does not shrink toward zero as iterations approach a local minimum, the termination criterion for nonsmooth problems can be based on a sufficiently small relative decrease in the objective function value.

## VI. [Newton-CG Method](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=Newton-CG%E6%B3%95&zhida_source=entity)

### (1) Complexity of Oracles at Different Orders

For multivariate functions, computing the Hessian has complexity at least $O(n^{2})$, and computing the inverse of the Hessian is roughly $O(n^{3})$, significantly higher than the $O(n)$ complexity of computing gradients or [function values](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E5%87%BD%E6%95%B0%E5%80%BC&zhida_source=entity) (per the cheap gradient theorem and the Baur-Strassen theorem). However, since

$$
\nabla f(x+\alpha \xi)=\nabla f(x)=\alpha \nabla^{2}f(x)\xi+o(|\alpha|)\Rightarrow \nabla^{2} f( x)\xi=\underset{\alpha \rightarrow 0}{lim}\frac{\nabla f(x+\alpha \xi)-\nabla f(x)}{\alpha}
$$

computing a [Hessian-vector product](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=Hessian-vector+product&zhida_source=entity) is equivalent to evaluating the gradient twice, so its complexity is of the same order as gradient computation.

### (2) Embedding CG into Newton's Method

Leveraging this, one can use the CG method to solve the linear system $Md=-g$ arising in the Newton step, though scaling (preconditioning) techniques are often introduced to improve the condition number. For instance, one may estimate the local Hessian or its inverse to estimate the eigenvalues of $M$, or use an L-BFGS method with a small $m$ (sliding window) as a preconditioner, solving the transformed problem $\hat M^{-\frac{1}{2}}M\hat M^{-\frac{1}{2}}$ to obtain $\hat d^{*}$, and then applying $\hat M^{-1}\hat d^{*}$.

Moreover, this linear system need not be solved very accurately; it suffices that $\underset{g \rightarrow 0}{lim}\frac{||\hat d^{*}-d^{*}||}{||g||}=0$ for Newton's method to converge, nearly as well as with an exact solve. The key is ensuring that accuracy improves as the gradient decreases. In nonconvex optimization, the gradient is often large and the direction discrepancy can be substantial; a pragmatic local remedy is to use $(M+\varepsilon I)d=-g$ with $\varepsilon=\frac{||g||_{\infty}}{100}$, ensuring the discrepancy remains two [orders of magnitude](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E6%95%B0%E9%87%8F%E7%BA%A7&zhida_source=entity) smaller than $g$, thereby approximately satisfying the above condition.

### (3) Truncated Newton-CG Method

The Newton-CG step is initialized at 0 to keep the search direction as stable as possible; in addition, only steps within the positive-definite part of the Hessian are retained, truncating directions of negative curvature (non-positive-definiteness indicates that the objective is far from being locally convex near the optimum). For the negative-curvature case, if $j=1$, a gradient step is used instead; otherwise, the iteration is simply broken without updating the optimization step, since continuing could cause an ascent.

$$
x^{1}\leftarrow x_{init},k\leftarrow1 \\ while\ \ ||\nabla f(x^{k})||>\delta \\\ \ \ \ \ \ \varepsilon\leftarrow min\{1,\frac{||\nabla f(x^{k})||}{10}\} \\\ \ \ \ \ \ d^{1}\leftarrow 0,v^{1}\leftarrow -\nabla f(x^{k}),u^{1}\leftarrow v^{1}, j\leftarrow 1 \\ \ \ \ \ \ \ while \ \ ||v^{j}||>\varepsilon^{k}||\nabla f(x^{k})|| \\ \ \ \ \ \ \ \ \ \ \ \ \ if \ \ (u^{j})^{T}\nabla^{2} f(x^{k})u^{j} \leq 0 \\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \  if \ \ j=1 \\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \  d^{j}\leftarrow -\nabla f(x^{k}) \\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ end \ \ if \\ \ \ \ \ \ \ \ \ \ \ \ \  break \\ \ \ \ \ \ \ \ \ \ \ \ \ end \ \ if \\ \ \ \ \ \ \ \ \ \ \ \ \ \alpha \leftarrow \frac{||v^{j}||^{2}}{(u^{j})^{T}\nabla^{2} f(x^{k})u^{j}}   \\ \ \ \ \ \ \ \ \ \ \ \ \ d^{j+1}\leftarrow d^{j}+\alpha u^{j} \\ \ \ \ \ \ \ \ \ \ \ \ \  v^{j+1}\leftarrow v^{j}-\alpha \nabla^{2} f(x^{k})u^{j}  \\ \ \ \ \ \ \ \ \ \ \ \ \  \beta \leftarrow \frac{||v^{j+1}||^{2}}{||v^{j}||^{2}}  \\ \ \ \ \ \ \ \ \ \ \ \ \  u^{j+1}\leftarrow v^{j+1}+\beta u^{j}  \\ \ \ \ \ \ \ \ \ \ \ \ \    j \leftarrow j+1  \\ \ \ \ \ \ \ end \ \ while \\ \ \ \ \ \ \ \alpha \leftarrow backtracking \ \ line \ \  search(Armijo) \\ \ \ \ \ \ \  x^{k+1}\leftarrow x^{k} +\alpha d^{j} \\ end \ \ while
$$

Compared with L-BFGS, Newton-CG is on average faster and can achieve better accuracy; the former typically stagnates around $10^{-8}$. An engineering rule of thumb is that an algorithm using only zeroth- and first-order oracles can rarely drive $|| \nabla f||$ below $10^{-8}$, whereas incorporating second-order or partial second-order information enables $|| \nabla f||$ to reach the $10^{-12}$ scale.
