记录一下优化学习过程中一些知识，发现这些细节过一段时间就会忘记不少，而且在不同地方不同书上内容有出入，这里做一下整合。

## 一、步长选取

### （一）平凡的步长

常数步长：经验性的、依赖初值地选取，太大会震荡发散、太小会收敛很慢，只有合适的时候才能做到快速稳定，总之不是很智能。

渐消步长：适用性很广，在函数非光滑、梯度有噪声时采用[Robbins－Monro rule](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=Robbins%EF%BC%8DMonro+rule&zhida_source=entity)可以保证收敛，但是[收敛速率](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E6%94%B6%E6%95%9B%E9%80%9F%E7%8E%87&zhida_source=entity)慢，通常都是条件差且对[收敛速度](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E6%94%B6%E6%95%9B%E9%80%9F%E5%BA%A6&zhida_source=entity)没太多要求的时候使用。

### （二）线搜索

1.精确线搜索[\[1\]](#ref_1)

通常非平凡。在单峰区间假设下，利用零阶Oracle有黄金分割搜索与[二次插值法](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E4%BA%8C%E6%AC%A1%E6%8F%92%E5%80%BC%E6%B3%95&zhida_source=entity)，前者线性收敛收敛比约为0.618，后者则超线性收敛，阶数为1.3；利用一阶Oracle同样可以采用二次与三次插值方法，前者收敛阶数为1.618，后者则为[二阶收敛](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E4%BA%8C%E9%98%B6%E6%94%B6%E6%95%9B&zhida_source=entity)；利用二阶Oracle有Newton法，至少二阶收敛。有关其[算法映射](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E7%AE%97%E6%B3%95%E6%98%A0%E5%B0%84&zhida_source=entity)的封闭性与[全局收敛性](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E5%85%A8%E5%B1%80%E6%94%B6%E6%95%9B%E6%80%A7&zhida_source=entity)可见[\[1\]](#ref_1)的185页。

2.非精确线搜索

易于实现且实用性强。

[Armijo准则](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=Armijo%E5%87%86%E5%88%99&zhida_source=entity)保证了充分下降： $f(x^k)-f(x^k+\alpha d) \geq -c\cdot\alpha d^T \nabla f(x^k)\$其中 $\alpha$ 代表步长， $d$ 代表优方向， $c$ 代表一个可调参数，通常取 $c\in(0,1)$。可以利用回溯线搜索实现。

[弱Wolfe准则](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E5%BC%B1Wolfe%E5%87%86%E5%88%99&zhida_source=entity)除充分下降外还对[斜率](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E6%96%9C%E7%8E%87&zhida_source=entity)产生要求，[强Wolfe准则](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E5%BC%BAWolfe%E5%87%86%E5%88%99&zhida_source=entity)则是对斜率有更强的要求，避免了过冲震荡。一般弱的就够了，但是如果对实现有信心，可以使用强的版本，实际上两者表现差不多。实际上弱的有一些独特的优势，在[病态函数](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E7%97%85%E6%80%81%E5%87%BD%E6%95%B0&zhida_source=entity)上优化更鲁棒，更常用；强的常配合一些基于插值或拟合的线搜索方法进行，而这类线搜索方法为了不会太病态会假设目标函数二阶[连续可微](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E8%BF%9E%E7%BB%AD%E5%8F%AF%E5%BE%AE&zhida_source=entity)。

弱Wolfe准则可以使用Lewis&Overton线搜索实现：

$$
l \leftarrow 0(lower bound) , u \leftarrow + \infty(up bound) , \alpha \leftarrow 1 \\ repeat \\  \ \ \ \ \ \ if\ \ f(x^{k})-f(x^{k}+\alpha d)<-c_{1}\alpha d^{T}\nabla f(x^{k})(\alpha太大)  \\  \ \ \ \ \ \ \ \ \ \ \ \ u \leftarrow \alpha  \\ \ \ \ \ \ \ else \ \ if \ \  d^{T}\nabla f(x+\alpha d )<c_{2}d^{T}\nabla f(x^{k})(\alpha太小)  \\  \ \ \ \ \ \ \ \ \ \ \ \ l \leftarrow \alpha  \\  \ \ \ \ \ \ else  \\  \ \ \ \ \ \ \ \ \ \ \ \ return \ \ \alpha(if和else\ \ if中一个成立则直接跳出)  \\  \ \ \ \ \ \ if\ \ u<+ \infty  \\   \ \ \ \ \ \ \ \ \ \ \ \ \alpha \leftarrow (l+u)/2(缩为上一步\alpha 与本步 \alpha 之间)   \\  \ \ \ \ \ \ else    \\   \ \ \ \ \ \ \ \ \ \ \ \ \alpha \leftarrow 2l   (上一步\alpha 的两倍)\\   end \ \ repeat
$$

在一些例子中，回溯线搜索和精确线搜索在同一精度要求下迭代次数相差无几，但是单步的[时间复杂度](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E6%97%B6%E9%97%B4%E5%A4%8D%E6%9D%82%E5%BA%A6&zhida_source=entity)却大相径庭。

### （三）信赖域

## 二、一阶方法

### （一）[梯度下降法](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E6%A2%AF%E5%BA%A6%E4%B8%8B%E9%99%8D%E6%B3%95&zhida_source=entity)

对梯度流 $\dot x(t)=\nabla f(x(t))，x(0)=x_{0}$ ，若其满足一阶Lipschitz，则由Picard存在唯一性定理可知该方程存在唯一解。且对于一个在 $x_{0}$ 附近正定，[梯度](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=4&q=%E6%A2%AF%E5%BA%A6&zhida_source=entity)（半）负定的 $f$ ，直接可以作为（局部的）Lyapunov函数，判断梯度流将稳定于 $f$ 的驻点。

使用前向Euler法进行[离散化](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E7%A6%BB%E6%95%A3%E5%8C%96&zhida_source=entity)可以得到通常的梯度步 $x^{k+1}=x^{k}-\alpha \nabla f(x^{k})$ ， $\alpha$ 为离散步长。采用前向Euler离散虽然容易过冲，但是相应的计算量会比隐式离散方法（比如三阶Hermite-Simpson、隐式中点法、后向Euler法）或者四阶Runge-Kutta法要小很多。当然有一个自然的想法是通过一个更稳定的[离散化方法](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E7%A6%BB%E6%95%A3%E5%8C%96%E6%96%B9%E6%B3%95&zhida_source=entity)来降低梯度步在大[条件数](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E6%9D%A1%E4%BB%B6%E6%95%B0&zhida_source=entity)下的震荡。但是更本质的解决此问题的方式是引入“广义动量”，也就是研究众多加速一阶方法。

对于普通的梯度下降可以证明对于凸的、一阶Lipschitz的条件下满足 $|\nabla f(x^{k})|\leq \frac{\beta}{\sqrt{k(k+1)}}||x^{*}-x^{0}||$ 进一步有 $f(x^{k})- f(x^{*})\leq \frac{\beta}{2(k+1)}||x^{*}-x^{0}||^{2}$ 算术收敛。

当条件增强至严格凸时，结果也会增强到线性收敛，这可以通过研究二次情形下的收敛特性得到。二次情形下梯度下降变为 $x^{k+1}=x^{k}-g^{k}/r^{k}$ ，其中 $r$ 为Rayleigh商。利用显式地椭球公式与Kantorovich[不等式](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E4%B8%8D%E7%AD%89%E5%BC%8F&zhida_source=entity)，容易得到对于 $E(x)=\frac{1}{2}(x-x^{*})^{T}Q(x-x^{*})$ ，有$E(x^{k+1})\leq (\frac {A-a}{A+a})^{2}E(x^{k})=(\frac {r-1}{r+1})^{2}E(x^{k})$，收敛比只与 $Q$ 的最大最小特征值之比（称为条件数）有关。非二次情形下无非是收敛比小于等于这个值（靠近局部最优时与二次情形等价）。这样自然也就引出尺度化改善条件数加快收敛的作用：对于 $Ty=x$ ，命 

$$
h(y)=f(Ty)\Rightarrow  d_{y}=-\nabla h=-T^{T}\nabla f\Rightarrow d_{x}=-TT^{T}\nabla f, \ \ \nabla ^{2}h(y)=T^{T}\nabla ^{2}f(Ty)T
$$

引起搜索方向和条件数的改变。显然对于[正交矩阵](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E6%AD%A3%E4%BA%A4%E7%9F%A9%E9%98%B5&zhida_source=entity) $T$ ，搜索方向不变同时优化速度也不变。

非二次的强[凸函数](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E5%87%B8%E5%87%BD%E6%95%B0&zhida_source=entity)（Hessian正定有界）对精确线搜索有 $f(x^{k+1})-f^{*}\leq (1-\frac{1}{r})(f(x^{k})-f^{*})$ ，对Armijo准则的回溯线搜索 $f(x^{k+1})-f^{*}\leq (1-\frac{2c}{r})(f(x^{k})-f^{*})$ 均为线性收敛。

### （二）加速一阶算法

## 三、修正阻尼[Newton法](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=2&q=Newton%E6%B3%95&zhida_source=entity)

$\dot x \left( t \right)=-\nabla^{-2}f\left( x(t) \right)\nabla f \left( x \left( t \right)\right)$ 离散化后得到 $x^{k+1}=x^{k}+d^{k}=x^{k}-\alpha H^{-1}\left( x^{k} \right)\nabla f\left( x^{k} \right)$ 作为二阶算法，很好地应对了条件数差、收敛慢的问题。迭代次数大大下降，收敛速率快，但是单步的成本大大上升。求解Newton步本质上是在求解[线性方程组](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E7%BA%BF%E6%80%A7%E6%96%B9%E7%A8%8B%E7%BB%84&zhida_source=entity) $Md=-\nabla f(x)$ ，那么就会有一些技术上的问题：

### （一）阻尼与Tkanov正则化

阻尼即Newton步步长 $\alpha$ 在靠近在局部最优时约为1，远离时则缩小步长。正则化确保正定来取逆，既避免了迭代过程中的一些病态、确保下降，还处理了数值上的[舍入误差](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E8%88%8D%E5%85%A5%E8%AF%AF%E5%B7%AE&zhida_source=entity)奇异问题。

当 $f$ 凸，Hessian需要正定，选择 $M=\nabla^{2}f(x)+\varepsilon I,\varepsilon =min \{ 1,||\nabla f(x)  ||_{\infty} \} /10$ 相当于在目标函数里计入对步长的惩罚项$\varepsilon \Delta x^{T}\Delta x, \ \ \Delta x=x^{k+1}-x^{k}$ 。检验正定可以使用Cholesky分解。

而非凸时则稍微复杂一点，需要考虑Bunch－Kaufman分解的特性。

### （二）[矩阵分解](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E7%9F%A9%E9%98%B5%E5%88%86%E8%A7%A3&zhida_source=entity)

在 $f$ 凸时，要求正定，可以使用Cholesky分解 $M=LL^{T}$ 求解Newton步；如果非凸，那么Hessian可以不定，可以使用Bunch-Kaufman分解 $M=LDL^{T}$ ，其中 $D$ 是分块对角矩阵（[三对角矩阵](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E4%B8%89%E5%AF%B9%E8%A7%92%E7%9F%A9%E9%98%B5&zhida_source=entity)），块大小有一阶和二阶，一阶为非负特征值、二阶特征值一正一负，很容易去正则化修正得到 $\tilde D$ 。

### （三）收敛性

可以证明在局部最优解附近Newton法具有二阶收敛性。此外，可以引入尺度化变换

$$
Ty=x，T=(\nabla ^{2}f(x^{k}))^{-\frac{1}{2}}
$$

关于 $y$ 的梯度步是关于 $x$ 的Newton步，而 $y$ 梯度步收敛速度由 $(\nabla ^{2}f(x^{k}))^{-\frac{1}{2}}\nabla^{2}f(x)(\nabla ^{2}f(x^{k}))^{-\frac{1}{2}}$ 的条件数确定

## 四、[共轭方向法](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E5%85%B1%E8%BD%AD%E6%96%B9%E5%90%91%E6%B3%95&zhida_source=entity)

### （一）线性[共轭梯度法](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E5%85%B1%E8%BD%AD%E6%A2%AF%E5%BA%A6%E6%B3%95&zhida_source=entity)（linear CG）

实际上源于一种有效的大规模线性求解方法（可以作为直接法或[迭代法](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E8%BF%AD%E4%BB%A3%E6%B3%95&zhida_source=entity)），通过求 $Ax$ 求解 $Ax=b$ ，其中 $A$ 正定。这也就等价于求解优化问题$\underset{x}{min}\frac{1}{2}x^{T}Ax-b^{T}x$ 。这种方法在二次问题上相当于梯度下降与Newton法的折衷，前者走折线路径、后者一步到达，而共轭方向法则是找到对于此问题的共轭方向，依照共轭方向走。对于n个共轭方向 $\{ u^{i}\}$，可以使用精确步长 

$$
\alpha \leftarrow \frac{b^{T}u^{k}-(x^{k})^{T}Au^{k}}{(u^{k})^{T}Au^{k}},x^{k+1}\leftarrow x^{k}+\alpha u^{k}
$$

 在n步得到 $Ax=b$ 的精确解。

通过对[线性无关向量组](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E7%BA%BF%E6%80%A7%E6%97%A0%E5%85%B3%E5%90%91%E9%87%8F%E7%BB%84&zhida_source=entity) $\{v^{i}\}$ 进行共轭Gram-Schmidt[正交化](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E6%AD%A3%E4%BA%A4%E5%8C%96&zhida_source=entity)

$$
u^{k}=v^{k}\sum_{j=1}^{k-1}{proj_{u^{j}}(v^{k})},\ \ proj_{u}(v)=\frac{<u,v>_{A}}{<u,u>_{A}}u,\ \ <u,v>_{A}=u^{T}Av
$$

可以获得共轭方向，不过我们还是要获得一组线性无关向量组，此外每个 $v$ 都要在所有的 $u$ 上投影，计算复杂度为 $O(\frac {k(k-1)}{2})=O(k^2)$ 即 $O(n^{2})$ ，很高。但是我们可以证明一些非常巧妙的结果：

可以按照 $v^{k}=b-Ax^{k}$ [增量式](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E5%A2%9E%E9%87%8F%E5%BC%8F&zhida_source=entity)选取 $v^{k}$ （构建了 $v^{k}$ 的[递推关系](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E9%80%92%E6%8E%A8%E5%85%B3%E7%B3%BB&zhida_source=entity)），并且有 $proj_{u^{j}}(v^{k})=0,\forall j\leq k-2$ ，我们就得到了一个短递归序列 

$$
u^{k}=v^{k}\sum_{j=1}^{k-1}{proj_{u^{j}}(v^{k})}=v^{k}+ \frac {||v^{k}||^{2}}{||v^{k-1}||^{2}}u^{k-1}
$$

 .

最终算法如下，只需要计算matrix-vector乘积 $Au^{k}$ 。这带来了另外的好处，就是隐式地考虑了稀疏性，无需使用一些[启发式方法](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E5%90%AF%E5%8F%91%E5%BC%8F%E6%96%B9%E6%B3%95&zhida_source=entity)去保持 $A$ 矩阵分解后的稀疏性。

$$
x^{1}\leftarrow x_{init} ,v^{1} \leftarrow b-Ax^{1} ,u^{1}\leftarrow v^{1} , k \leftarrow 1 \\ while \ \ v^{k}\ne 0 \ \ (||v^{k}||\geq \varepsilon) \\ \ \ \ \ \ \  \alpha \leftarrow \frac{||v^{k}||^{2}}{(u^{k})^{T}Au^{k}} \\ \ \ \ \ \ \ x^{k+1}\leftarrow x^{k}+\alpha u^{k} \\ \ \ \ \ \ \ v^{k+1}\leftarrow v^{k}-\alpha Au^{k} \\  \ \ \ \ \ \ \beta \leftarrow \frac{||v^{k+1}||^{2}}{||v^{k}||^{2}} \\ \ \ \ \ \ \ u^{k+1}\leftarrow v^{k+1}+\beta u^{k} \\ \ \ \ \ \ \ k \leftarrow k+1 \\end  \ \ while \\return \ \ x^{k}
$$

此外，该方法也几乎是最伟大的[线性求解器](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E7%BA%BF%E6%80%A7%E6%B1%82%E8%A7%A3%E5%99%A8&zhida_source=entity)，在相当大的条件数下仍保持了极少次数的迭代。

## 五、[BFGS法](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=BFGS%E6%B3%95&zhida_source=entity)

对于规模为 $\mathbb R^{n }$ 的问题，梯度步[计算成本](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E8%AE%A1%E7%AE%97%E6%88%90%E6%9C%AC&zhida_source=entity) $O(N)$ ，Newton步的[存储成本](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E5%AD%98%E5%82%A8%E6%88%90%E6%9C%AC&zhida_source=entity) $O(N^{2})$ ，计算成本 $O(N^{3})$ 。此外，对于二次近似效果较差的情况，Newton步的[效费比](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E6%95%88%E8%B4%B9%E6%AF%94&zhida_source=entity)并不划算。当Hessian非正定时，会出现无穷大的步长或上升步。对$Md=-\nabla f(x)$中的矩阵 $M$ ，我们希望不需要做[二阶导](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E4%BA%8C%E9%98%B6%E5%AF%BC&zhida_source=entity)增加计算、轻量紧凑减少存储，同时还能包含[曲率](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E6%9B%B2%E7%8E%87&zhida_source=entity)信息、保证下降方向，最好还可以有一个[闭式解](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E9%97%AD%E5%BC%8F%E8%A7%A3&zhida_source=entity)。

### （一）推导

$$
\nabla f(x+d)=\nabla f(x)+\nabla ^{2}f(x)d +\int_{0}^{1}(\nabla^{2}f(x+td)-\nabla^{2}f(x))dt \\ \Rightarrow \nabla f(x)-\nabla f(y)\approx H(x-y)
$$

对于上述近似记为 $\Delta g= M\Delta x$ 称为正割条件，为了避免去求逆，改为 $\Delta x=B\Delta g,MB=I$ ，使用梯度之差近似Hessian，显然这个线性方程组是欠定的。那么假设迭代进行到第k步，已知 $B^{k}$ $\Delta x=x^{k+1}-x^{k},\Delta g=\nabla f(x^{k+1})-\nabla f(x^{k})$

在凸函数假设下基于[先验](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E5%85%88%E9%AA%8C&zhida_source=entity) $B^{k}$ ，求解优化问题 $\\\underset B{min}||B-B^{k}||^{2} \\　s.t.B=B^{T} \\ 　　 \Delta x=B \Delta g$

由于B中元素尺度不同，进行尺度化，设更新前后Hessian平均 $H= \int _{0}^{1}\nabla^{2}f((1-\tau)x^{k}+\tau x^{k+1})d\tau$ $\\\underset B{min}||H^{1/2}(B-B^{k})H^{1/2}||^{2} \\　s.t.B=B^{T} \\ 　　 \Delta x=B \Delta g$

可以解得与H无关的闭式解，我们就能获得BFGS法的结果 

$$
B^{k+1}=(I- \frac {\Delta x\Delta g^{T}}{\Delta g^{T}\Delta x})B^{k}(I- \frac {\Delta g\Delta x^{T}}{\Delta g^{T}\Delta x})+\frac {\Delta x\Delta x^{T}}{\Delta g^{T}\Delta x}
$$

，且 $B^{0}=I$ 。

### （二）保证下降与收敛

为了保证下降即 $B^{k}\succ 0$ ，可以证明只需满足 $\Delta g ^{T}\Delta x >0$ 。在强凸时上式自动满足，我们只需要Armijo准则得到步长即可。对于非凸、非光滑情形，使用满足弱Wolfe准则的非精确线搜索即可保证下降。

BFGS算法的复杂度为单步$O(N^{2})$，且可以达到[超线性收敛](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=2&q=%E8%B6%85%E7%BA%BF%E6%80%A7%E6%94%B6%E6%95%9B&zhida_source=entity)。对于有界次[水平集](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E6%B0%B4%E5%B9%B3%E9%9B%86&zhida_source=entity)、一阶Lipschitz的函数，谨慎更新条件保证了收敛 （在2001年前没有任何算法能保证BFGS法在[非凸函数](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E9%9D%9E%E5%87%B8%E5%87%BD%E6%95%B0&zhida_source=entity)上收敛，仅仅是实践表明非凸时几乎没失败过，2001年提出此条件后有人质疑该更新条件是否冗余，直到2013年文章A perfect example for the BFGS method，构造了一个几维的函数使BFGS+Wolfe条件无法收敛，才开始重视这个2001年的结果），不过由于BFGS方法特性，发散一般出现在优化初期，靠近局部极小处满足谨慎更新条件，所以工程上不加这个也挺稳定。

$$
B^{k+1}= \begin{cases} (I- \frac {\Delta x\Delta g^{T}}{\Delta g^{T}\Delta x})B^{k}(I- \frac {\Delta g\Delta x^{T}}{\Delta g^{T}\Delta x})+\frac {\Delta x\Delta x^{T}}{\Delta g^{T}\Delta x}  &   &{若\Delta g^{T}\Delta x>\varepsilon||g_k||\Delta x^{T}\Delta x,\varepsilon =10^{-6}}  \\B^{k}&  &{其他}  \end {cases}
$$

### （三）有限记忆（L-BFGS）

在远离局部极小处的曲率信息不太重要尤其是非凸函数上许多步前可能属于不同的曲率方向，但是BFGS会保留历史信息，迭代多次后 $B^{k}$ 也会变得稠密，存储与计算更慢。可以加入遗忘机制，防止历史信息干扰、限制矩阵秩。设 $s^{k}=x^{k+1}-x^{k},y^{k}=g^{k+1}-g^{k},\rho^{k}=1/{s^{k}}^{T}y^{k}$ ，引入一个长为m的滑窗，有 $B^{k+1}\leftarrow BFGS(B^{k},y^{k},s^{k}),k\leftarrow k+1$ 循环m次（窗口未满则与普通BFGS等价），复杂度为 $O(mn^2)$ ，但是每一次只是在增量式更新，无需每次计算都算整个滑窗，这样我们可以构造[等价算法](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E7%AD%89%E4%BB%B7%E7%AE%97%E6%B3%95&zhida_source=entity)——双圈递归，但是复杂度却只有 $O(mn)$ .

$$
d \leftarrow g^{k} \\ for\ \ i=k-1,k-2,...,k-m \\ \ \ \ \ \ \ \ \alpha^{i}\leftarrow \rho^{i}{s^{i}}^{T}d \\ \ \ \ \ \ \ \ d \leftarrow d-\alpha^{i}y^{i} \\ end \ \ for \\ \gamma \leftarrow \rho^{k-1}{y^{k-1}}^{T}y^{k-1} \\ d \leftarrow d/\gamma \\ for \ \ i=k-m,k-m+1,...,k-1 \\ \ \ \ \ \ \ \ \beta \leftarrow \rho^{i}{y^{i}}^{T}d \\ \ \ \ \ \ \ \ d \leftarrow d+s^{i}(\alpha^{i}-\beta) \\ end\ \ for \\ return\ \ search \ \ direction \  \ d
$$

### （四）非光滑BFGS

当优化目标函数非光滑或者分片光滑时，梯度可能不存在、负的次梯度方向可能不是下降方向、曲率可能很大出现奇异。通常算法在处理非光滑时会报错。在2013年，Lewis&Overton设计了解决思路（收敛速率不高，但是对于非[光滑优化](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E5%85%89%E6%BB%91%E4%BC%98%E5%8C%96&zhida_source=entity)来说可以接受）。对于非光滑情形，强Wolfe条件可能会出现问题，而弱的版本可以正常工作。

由于梯度在非光滑情形不会随着迭代收敛到局部极小模长缩小。非光滑的终止条件可以用目标函数相对下降值足够小。

## 六、[Newton-CG法](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=Newton-CG%E6%B3%95&zhida_source=entity)

### （一）不同阶Oracle的复杂度

对于多元函数，计算Hessian的复杂度至少是 $O(n^{2})$ ，Hessian的逆的复杂度大概是 $O(n^{3})$ ，显著高于对梯度或[函数值](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E5%87%BD%E6%95%B0%E5%80%BC&zhida_source=entity)的计算复杂度 $O(n)$ （cheap gradient theorem和Baur-Strassen theorem）。但是由于

$$
\nabla f(x+\alpha \xi)=\nabla f(x)=\alpha \nabla^{2}f(x)\xi+o(|\alpha|)\Rightarrow \nabla^{2} f( x)\xi=\underset{\alpha \rightarrow 0}{lim}\frac{\nabla f(x+\alpha \xi)-\nabla f(x)}{\alpha}
$$

计算一个[Hessian-vector product](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=Hessian-vector+product&zhida_source=entity)，相当于算两次梯度，所以复杂度与梯度计算是同阶的。

### （二）将CG嵌入Newton法

利用这一点，可以使用CG方法求解Newton步中的线性方程组$Md=-g$，不过常常引入尺度化方法改善条件数。比如估计局部的Hessian或者其逆来估计 $M$ 的特征值，比如使用一个L-BFGS方法设置一个小的m（滑窗）作为preconditioner，求解 $\hat M^{-\frac{1}{2}}M\hat M^{-\frac{1}{2}}$ 对应问题得到 $\hat d^{*}$ 然后使用 $\hat M^{-1}\hat d^{*}$ 。

而且这个线性方程组无需求解得很精确，只需 $\underset{g \rightarrow 0}{lim}\frac{||\hat d^{*}-d^{*}||}{||g||}=0$ 即可让Newton法收敛，和精确求解差不多一样。关键在于如何保证梯度减小时精度提高，非凸优化很多时候梯度很大，方向差距可以很大，局部可使用 $(M+\varepsilon I)d=-g,\varepsilon=\frac{||g||_{\infty}}{100}$ 这样一种很工程的方法让差值总比 $g$ 小两个[数量级](https://zhida.zhihu.com/search?content_id=259971543&content_type=Article&match_order=1&q=%E6%95%B0%E9%87%8F%E7%BA%A7&zhida_source=entity)来近似满足上述条件。

### （三）截断Newton-CG法

Newton-CG步以0为初值，使寻优方向尽可能稳定；此外只保留Hessian中正定部分的步，截断负曲率方向（非正定说明离最有附近局部凸较远）。对于负曲率情况如果j为1则使用梯度步代替，否则直接break不更新优化步，否则可能导致上升。

$$
x^{1}\leftarrow x_{init},k\leftarrow1 \\ while\ \ ||\nabla f(x^{k})||>\delta \\\ \ \ \ \ \ \varepsilon\leftarrow min\{1,\frac{||\nabla f(x^{k})||}{10}\} \\\ \ \ \ \ \ d^{1}\leftarrow 0,v^{1}\leftarrow -\nabla f(x^{k}),u^{1}\leftarrow v^{1}, j\leftarrow 1 \\ \ \ \ \ \ \ while \ \ ||v^{j}||>\varepsilon^{k}||\nabla f(x^{k})|| \\ \ \ \ \ \ \ \ \ \ \ \ \ if \ \ (u^{j})^{T}\nabla^{2} f(x^{k})u^{j} \leq 0 \\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \  if \ \ j=1 \\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \  d^{j}\leftarrow -\nabla f(x^{k}) \\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ end \ \ if \\ \ \ \ \ \ \ \ \ \ \ \ \  break \\ \ \ \ \ \ \ \ \ \ \ \ \ end \ \ if \\ \ \ \ \ \ \ \ \ \ \ \ \ \alpha \leftarrow \frac{||v^{j}||^{2}}{(u^{j})^{T}\nabla^{2} f(x^{k})u^{j}}   \\ \ \ \ \ \ \ \ \ \ \ \ \ d^{j+1}\leftarrow d^{j}+\alpha u^{j} \\ \ \ \ \ \ \ \ \ \ \ \ \  v^{j+1}\leftarrow v^{j}-\alpha \nabla^{2} f(x^{k})u^{j}  \\ \ \ \ \ \ \ \ \ \ \ \ \  \beta \leftarrow \frac{||v^{j+1}||^{2}}{||v^{j}||^{2}}  \\ \ \ \ \ \ \ \ \ \ \ \ \  u^{j+1}\leftarrow v^{j+1}+\beta u^{j}  \\ \ \ \ \ \ \ \ \ \ \ \ \    j \leftarrow j+1  \\ \ \ \ \ \ \ end \ \ while \\ \ \ \ \ \ \ \alpha \leftarrow backtracking \ \ line \ \  search(Armijo) \\ \ \ \ \ \ \  x^{k+1}\leftarrow x^{k} +\alpha d^{j} \\ end \ \ while
$$

相比L-BFGS，Newton-CG平均意义上更快、可以达到更好的精度，前者基本到达$10^{-8}$就停滞了。有一个工程上的结论，如果一个算法只利用零阶和一阶Oracle，基本上很难让 $|| \nabla f||$ 下降到 $10^{-8}$ 以下，如果获取二阶或者部分二阶信息才能让$|| \nabla f||$达到$10^{-12}$量级。
